# Research Skills

Reusable agent skills for working with conference proceedings PDFs.

## Skills

- [Paper Analysis](paper-analysis.md) - Analyze conference proceedings PDFs to produce detailed, evidence-grounded paper notes with full transcription and structured analysis.
- [Proceedings Page Ranges](proceedings-page-ranges.md) - Identify and verify physical PDF page ranges for papers in conference proceedings.

## Usage

These skills are designed to be used by AI coding agents. Copy them into your agent's skills directory as appropriate for your setup.
